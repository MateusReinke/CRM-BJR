Descrição Geral

Crie uma aplicação web responsiva (compatível com desktop e mobile) para gerenciar a empresa BJR Centro Automotivo, que possui duas unidades físicas:

São Paulo (SP1) → cor exclusiva azul

São Paulo (SP2) → cor exclusiva Cinza

Sorocaba (SOR) → cor exclusiva verde

Visão Global (todas as unidades) → cor exclusiva vermelho

O sistema deve oferecer gestão de clientes, veículos, ordens de serviço, agendamentos, estoque, financeiro e funcionários.
Cada unidade deve ter dados separados, mas também deve existir visão consolidada.

1. Requisitos Técnicos

Aplicação responsiva (PC e mobile).

Frontend: React.js + Tailwind CSS (interface moderna, responsiva e rápida).

Backend: Node.js + Express.

Banco de dados: PostgreSQL (relacional, com suporte multiunidade).

Autenticação de usuários: JWT com níveis de permissão (admin, gerente, mecânico, vendedor).

APIs RESTful para CRUD completo.

Exportação de relatórios em PDF e Excel.

Backup automático diário do banco de dados.

3. Regras de Negócio

Cada unidade deve ter cor exclusiva e sigla obrigatória em OS, relatórios e estoque.

O painel lateral deve permitir sempre alternar: SPI, SOR ou Todas as Unidades.

Comissões de mecânicos e vendedores devem ser calculadas automaticamente em relatórios.

Toda comunicação com clientes (WhatsApp/E-mail) deve usar os dados da unidade correspondente.

Relatórios devem permitir filtro por unidade ou visão global.

4. Diferenciais Desejados

Dashboard inicial com KPIs principais.

Chat interno para comunicação entre equipe.

Leitura de placa via câmera (opcional).

Exportação de relatórios em PDF e Excel.
